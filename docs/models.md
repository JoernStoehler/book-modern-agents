# Models

Loosely ordered from most capable (and slowest/most expensive) to least capable (and fastest/cheapest). Benchmark results are not very meaningful for agent tasks, so this ranking is based on practical experience.

| Tier | Model | Provider | Available On |
|------|-------|----------|-------------|
| Top | Claude Opus 4.6 | Anthropic | Pro ($20), Max ($100/$200) |
| Top | GPT-5.3-Codex | OpenAI | Plus ($20), Pro ($200) |
| Strong | GPT-5.2 | OpenAI | Plus ($20), Pro ($200) |
| Strong | Gemini 3.0 Pro | Google | Free (limited), AI Pro ($20), AI Ultra ($250) |
| Mid | Claude Sonnet 4.5 | Anthropic | Pro ($20), Max ($100/$200) |
| Fast | Gemini 3.0 Flash | Google | Free (generous), AI Pro ($20) |
| Fast | Claude Haiku 4.5 | Anthropic | Pro ($20), Max ($100/$200) |
| Fast | GPT-5-mini | OpenAI | Plus ($20), Pro ($200) |

GitHub Copilot ($20) gives access to models from multiple providers, with a shared usage quota.
